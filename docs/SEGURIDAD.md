# Seguridad

- bcrypt con costo configurable.
- Access token de corta duracion.
- Refresh token hasheado y revocable.
- Validacion zod en endpoints.
- Permisos y alcance se validan siempre en backend.
- CORS configurable por entorno.
- Secretos solo en backend.
- Auditoria de cambios y accesos sensibles.
- Adulto mayor no es usuario autenticable.
- Endpoints de cron y sincronizacion protegidos.
